Bespicy
=======

A modern web platform for food lovers — discover personalized recipes, smart meal planning, and innovative cooking solutions in one place. 🍜

Features
--------

*   Ingredient-based recipe recommendations
    
*   Smart recipe matching using TF-IDF & cosine similarity
    
*   Search recipes by ingredients and cooking time
    
*   Nearest restaurant finder
    
*   Calorie calculator for meal tracking
    
*   Fast and responsive modern UI
    
*   Personalized food discovery experience
    

Tech Stack
----------

*   **Frontend:** React.js, Tailwind CSS
    
*   **Backend:** Node.js, FastAPI
    
*   **Machine Learning:** scikit-learn, pandas
    

How It Works
------------

*   Users enter available ingredients or preferences
    
*   The recommendation engine analyzes recipes using TF-IDF vectorization and cosine similarity
    
*   Relevant recipes are suggested instantly
    
*   Users can also explore nearby restaurants and calculate meal calories
